Bold and italic text you can paste anywhere.

A small, free Mac app that lives in your menu bar. Type your text, click a style, and paste it into LinkedIn, X, Slack, Teams or email. The styling goes with it because it's built from Unicode characters, not formatting.

    Install

    About a minute, and you only do the security step once.

    1. Download the zip

      UnicodeStyler.zip from the latest GitHub release.

    2. Move it to Applications

      Double-click the zip to unpack it, then drag Unicode Styler into your Applications folder.

    3. Open it once and approve it

      macOS will say it can't verify the developer. Follow the steps on the right. You only do this the first time.

    4. Look in your menu bar

      Click the B/I/U icon, type your text, and click a style.

    Why macOS warns you, and how to open it

    The app isn't signed with a paid Apple Developer ID yet, so Gatekeeper blocks it the first time. It isn't damaged. To open it:

    1. Open the app once and click Done on the warning.
    2. Go to System Settings › Privacy & Security.
    3. Scroll down and click Open Anyway next to Unicode Styler.

    Prefer Terminal? This removes the download flag:

    xattr -dr com.apple.quarantine "/Applications/Unicode Styler.app"

    How it works

    The styled text isn't formatting. These are different characters. Unicode's Mathematical Alphanumeric Symbols block has complete alphabets in bold, italic and sans-serif, made for writing math. Each one starts at a fixed code point, so converting a letter is one addition.

    styled = start + (letter − A)

    • Italic h is in a different place.Unicode already had ℎ as the Planck constant (U+210E), so the italic alphabet has a gap there. The app maps it separately.
    • Italic has no digits.Numbers stay plain in italic styles. Bold styles have their own digits.
    • Everything else passes through.Spaces, punctuation and emoji are left as they are.
    AStyleStarts at
    𝐀BoldU+1D400
    𝐴ItalicU+1D434
    𝑨Bold italicU+1D468
    𝗔Sans boldU+1D5D4
    𝘈Sans italicU+1D608
    𝘼Sans bold italicU+1D63C

    Use it for emphasis rather than whole posts. Screen readers may read these characters one at a time, and search won't match 𝐁𝐨𝐥𝐝 to Bold.

    Build it yourself

    The whole app is one Swift file and a build script. There's no Xcode project. You only need the Command Line Tools (xcode-select --install).

    git clone https://github.com/dalehassinger/UnicodeStyler.git
cd UnicodeStyler
chmod +x build.sh
./build.sh --install
