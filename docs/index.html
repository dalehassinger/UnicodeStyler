How it works

The styled text isn't formatting. These are different characters, so the style survives copy and paste into any app that takes text.

You typePlain textHello
Unicode StylerMaps each letterH → U+1D407
You pasteStyled text𝐇𝐞𝐥𝐥𝐨

Unicode's Mathematical Alphanumeric Symbols block (U+1D400 to U+1D7FF) has complete alphabets in bold, italic and sans-serif, made for writing math. Each one starts at a fixed code point, so converting a letter is one addition:

styled = start + (letter − 'A')

  • Italic h is somewhere else.Unicode already had ℎ as the Planck constant (U+210E), so the italic alphabet has a gap there. The app maps it separately.
  • Italic styles have no digits.Numbers stay plain in italic. Bold has its own 𝟎 to 𝟗.
  • Everything else passes through.Spaces, punctuation and emoji are left as they are.
AStyleStarts at
𝐀BoldU+1D400
𝐴ItalicU+1D434
𝑨Bold italicU+1D468
𝗔Sans boldU+1D5D4
𝘈Sans italicU+1D608
𝘼Sans bold italicU+1D63C

Use it for emphasis rather than whole posts. Screen readers may read these characters one at a time, and search won't match 𝐁𝐨𝐥𝐝 to Bold.

Private by design

It's a text converter. It doesn't need anything else.

Works offline

The app makes no network connections. The conversion happens on your Mac.

Nothing collected

No accounts, analytics or tracking. Your text is never saved.

Clipboard on request

It only reads your clipboard when you click Paste, and only writes to it when you click a style.

Open source

Download

About a minute to install. The security step only happens the first time.

macOS

Universal: Apple silicon and Intel
Download UnicodeStyler.zip

Version 1.1. Requires macOS 13 Ventura or later.

  1. Double-click the zip and drag Unicode Styler into Applications.
  2. Open it. macOS will say it can't verify the developer. Follow the steps below.
  3. Click the B/I/U icon in your menu bar, type your text, and click a style.

The app isn't signed with an Apple Developer ID yet, so Gatekeeper blocks it the first time. It isn't damaged. Click Done, go to System Settings › Privacy & Security, and click Open Anyway. Or run this in Terminal:

xattr -dr com.apple.quarantine "/Applications/Unicode Styler.app"

Windows and Linux

Any modern browser, nothing to install

The web version has all 10 styles, click to copy, keyboard shortcuts, and Light or Dark mode. Bookmark it, or install it from Edge or Chrome so it opens like an app. It works offline once loaded.
